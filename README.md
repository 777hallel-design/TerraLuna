# טרה-לונה · TerraLuna

לוח שנה ביודינמי לזריעה ולקטיף בלבד (בלי שתילה): ימי שורש, עלה, פרח ופרי לפי מיקום הירח במזלות, ירח עולה ויורד, וזמנים לא מומלצים (צמתי הירח, פריגיאה וליקויים).

## מה יש באפליקציה

- **חמש תצוגות**: שעתי, יומי, שבועי, חודשי ושנתי.
- **לחיצה על יום** פותחת הסבר מלא: מהלך היום לפי שעות, מה לזרוע ומה לקטוף, רשימת גידולים, מצב הירח, אירועים (מולד, צמתים, פריגיאה) ויומן גינה אישי.
- **"מתי לזרוע?"**: בוחרים גידול ופעולה (זריעה או קטיף לאחסון) ומקבלים את החלונות המתאימים בטווח שבוחרים, עם סימון ★ לחלונות הקטיף הטובים במיוחד (ירח עולה לפירות, עלים ופרחים, ירח יורד לשורשים).
- **חיבור ליומן**: מנוי (webcal) ליומן Google, Apple ו־Outlook, וגם הורדת קובץ ‎.ics. יש יומן לכל סוג יום ויומן של זמנים לא מומלצים בלבד, בעברית ובאנגלית.
- **זמנים לא מומלצים מלוח מריה טון**: בהגדרות אפשר להדביק את זמני ה־Unfavorable מהלוח שלכם. בכל שנה שמוזנים לה זמנים, הם מחליפים את הזמנים המחושבים.
- **הגידולים שלי**: בוחרים גידולים, והם מודגשים בלוח (🌱) ובסיכום היומי.
- **היום ומחר**: פס בראש כל תצוגה שמראה את סוג היום של היום ושל מחר, ואת הזמנים הלא מומלצים.
- **תזכורות בטלפון** דרך היומן: יומן "סיכום יומי" עם אירוע אחד לכל יום ותזכורת ב־20:00 בערב שלפני. בייצוא המותאם אפשר לבחור תזכורת בערב או בבוקר.
- **עונות זריעה בישראל**: טבלה של חודשי הזריעה לכל גידול. "מתי לזרוע?" מציג רק חלונות בעונה (אפשר להציג גם מחוץ לעונה), ובפירוט היום הגידולים בעונה מופיעים ראשונים.
- **זריחה ושקיעה של הירח והשמש** לפי מיקום: ערים בישראל, המיקום הנוכחי או קואורדינטות. מחושב בדפדפן, ובבדיקה מול Swiss Ephemeris הסטייה היא עד דקה וחצי.
- **הדפסה**: של התצוגה הנוכחית (A4 לרוחב), או של יום פתוח.
- **סנכרון בין מכשירים** דרך Supabase (ראו בהמשך).
- **העברה למכשיר אחר** בלי חשבון: קישור שמכיל את היומן, ההגדרות והזמנים שהזנתם. הנתונים לא נשמרים בשום שרת.
- **עובד בלי אינטרנט** (PWA) ואפשר להתקין אותו על הטלפון.

## עיצוב ונוחות

- אייקונים מצוירים (שורש, עלה, פרח, פרי ומופעי הירח), במקום אימוג'י שנראים אחרת בכל מכשיר.
- גופן Assistant לעברית.
- בטלפון יש סרגל לשוניות בתחתית המסך, ואפשר להחליק ימינה ושמאלה כדי לעבור בין חודשים.
- בכניסה הראשונה מופיע כרטיס קצר שמסביר איך קוראים את הלוח.

## נגישות

עברית מימין לשמאל ואנגלית; ניווט מלא במקלדת (חצים, Enter, Page Up/Down, T); תיאור מלא של כל יום לקוראי מסך; הקראה בקול של סיכום היום; הגדלת טקסט; ניגודיות גבוהה; מצב כהה; הפחתת תנועה; דוגמאות (פסים ונקודות) בנוסף לצבע, לעיוורי צבעים; המידע תמיד מופיע גם כאייקון וגם כטקסט ולא רק כצבע.

## איך החישוב עובד

| יסוד | מזלות | סוג יום |
|---|---|---|
| אדמה | שור, בתולה, גדי | 🥕 שורש |
| מים | סרטן, עקרב, דגים | 🥬 עלה |
| אוויר | תאומים, מאזניים, דלי | 🌼 פרח |
| אש | טלה, אריה, קשת | 🍅 פרי |

- כל המיקומים מחושבים עם **Swiss Ephemeris** (`ephemeris/generate.py`, ספריית `pyswisseph`).
- גלגל מזלות **סידריאלי (אסטרונומי)**, כלומר לפי הכוכבים בשמיים ולא לפי החלוקה הטרופית האסטרולוגית. המזלות **שווים, 30° כל אחד**, ותיקון הפרצסיה הוא לפי אייאנמשה Lahiri (כיום כ־24°). בדיקה ב־`tests/` מוודאת שהלוח לא חוזר בטעות לחישוב טרופי. הזמנים זהים בדקה לזמנים ב־astro-seek (יש על זה בדיקה ב־`tests/`).
- **צמתי הירח**: הרגע שבו קו הרוחב האקליפטי של הירח עובר דרך 0, פעמיים בחודש (צומת עולה וצומת יורד).
- **פריגיאה ואפוגיאה**: הנקודה הקרובה והרחוקה ביותר של הירח מכדור הארץ.
- **ירח עולה ויורד**: לפי נקודות המפנה בנטייה (deklination) של הירח. בחצי הכדור הדרומי ההגדרה מתהפכת (יש הגדרה לכך).
- **זמנים לא מומלצים**: 6 שעות לפני ואחרי צומת, 12 שעות לפני ואחרי פריגיאה וליקוי. אפשר לשנות את זה בהגדרות.
- הכול נשמר ב־UTC, והאפליקציה מציגה את הזמנים באזור הזמן שבחרתם.

## הרצה

```bash
pip install -r ephemeris/requirements.txt
npm run build      # מחשב את נתוני הירח (2020–2040) ובונה את קובצי ה־ics
npm test
npm run serve      # http://localhost:8080
```

הפריסה ל־GitHub Pages מתבצעת אוטומטית בכל push ל־`main` (`.github/workflows/pages.yml`). כדי שזה יעבוד, צריך להפעיל ב־Settings ← Pages את האפשרות Source: GitHub Actions. המנוי ליומנים עובד רק כשהאפליקציה מפורסמת בכתובת ציבורית.

## סנכרון בין מכשירים (Supabase)

נכנסים עם מייל, והיומן, ההגדרות וזמני מריה טון מסתנכרנים בין המכשירים. הלוח ממשיך לעבוד בלי אינטרנט. במקרה של התנגשות, העריכה האחרונה גוברת: לכל יום ביומן בנפרד, ולהגדרות ולזמני מריה טון כיחידה אחת. הגדרה חד־פעמית:

1. ב־Supabase: פותחים פרויקט חדש.
2. **SQL Editor** ← New query: מדביקים את התוכן של `supabase/schema.sql` ולוחצים Run. הקובץ יוצר את הטבלאות, ומגדיר הרשאות (Row Level Security) כך שכל אחד רואה רק את הנתונים שלו.
3. **Authentication ← URL Configuration**: ב־Site URL מזינים את כתובת האפליקציה (למשל `https://777hallel-design.github.io/TerraLuna/`), ומוסיפים אותה גם ל־Redirect URLs, יחד עם `http://localhost:8080` לבדיקות.
4. **Authentication ← Email Templates ← Magic Link**: מוסיפים לתבנית את השורה `{{ .Token }}`, כדי שהמייל יכיל גם קוד בן 6 ספרות. זה חשוב באייפון: כשהאפליקציה מותקנת על המסך, קישור מהמייל נפתח ב־Safari ולא באפליקציה, ואת הקוד אפשר להקליד ישירות באפליקציה.
5. **Project Settings ← API**: מעתיקים את ה־Project URL ואת המפתח `anon` `public` לקובץ `app/js/config.js`. המפתח הזה מיועד להיות ציבורי. **את המפתח `service_role` לא מכניסים לקוד ולא שולחים לאף אחד.**

הערות: שירות המיילים המובנה של Supabase מוגבל למספר קטן של מיילים בשעה. כשיהיו משתמשים רבים, כדאי לחבר שירות מייל משלכם (Authentication ← SMTP Settings, למשל Resend). פרויקט בתוכנית החינמית מושהה אחרי שבוע בלי פעילות.

## מבנה

```
ephemeris/generate.py   חישוב אירועי הירח ← app/data/<year>.json
app/js/core.js          תקופות, סיכום יומי, חלונות זריעה, אזורי זמן (בלי DOM)
app/js/i18n.js          טקסטים, הנחיות ביודינמיות ורשימת גידולים (עברית ואנגלית)
app/js/ics.js           ייצוא iCalendar (תקופות וסיכום יומי עם תזכורות)
app/js/astro.js         זריחה ושקיעה של הירח והשמש לפי מיקום
app/js/sync.js          סנכרון דרך Supabase
app/js/config.js        כתובת ומפתח ציבורי של Supabase
app/js/app.js           ממשק המשתמש
supabase/schema.sql     טבלאות והרשאות ל־Supabase
scripts/build-ics.mjs   יצירת יומני המנוי ב־app/calendar/
tests/                  בדיקות (node --test)
```

## רישיון

כן, מותר להשתמש ב־Swiss Ephemeris. היא חינמית בתנאי שהקוד של האפליקציה פתוח לציבור (רישיון AGPL), ולכן הפרויקט הזה מוגדר כ־AGPL-3.0. כדי להפיץ את האפליקציה בקוד סגור, צריך לקנות מ־Astrodienst רישיון מקצועי בתשלום חד־פעמי. Swiss Ephemeris רצה רק בזמן הבנייה (`ephemeris/generate.py`), והאפליקציה עצמה משתמשת רק בנתונים שהיא מייצרת.
